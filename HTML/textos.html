Tags de texto

As principas do HTML

1 - Títulos

Para titulos usa as tags do H1 ao h6.

2 - Parágrafos

Para criar um parágrafo no HTML usa-se a tag p.

3 - Negrito

Para colocar em negrito usa-se as tags B ou STRONG.

4 - Itálico

Para colocar em itálico usa-se as tags I ou EM.

5 - Taxado

Para colocar em tachado usa a tag S.

6 - Sublinhado

Para colocar em Sublinhado usa a tag U.

7 - Quebra de linha

Paras quebra de linha
usa a tag br.
